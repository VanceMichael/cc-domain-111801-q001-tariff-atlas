# TariffAtlas 来源约定

此服务管理税目范围展开、跨版编码解释及适用范围收件。
当前常规业务使用一个选定来源上下文处理直接列出的记录。目录请求为 `GET /tax/CN/R2`，返回 `edition`、`tariffs`，可附带 `chapters`。每个目录成员以 `id`、`href` 提供来源身份与原文位置，税目成员可另以 `relations` 声明关联资料位置；原文中的 `code`、`chapter` 和 `edition` 必须与目录一致。

## 记录含义

```json
{
  "code": "H-881",
  "edition": "R2",
  "rate": "4.5",
  "unit": "percent",
  "country": "CN",
  "description": "普通设备",
  "chapter": "88"
}
```

这里的字段是来源提供的原始声明，数值文本必须符合十进制规则，不能把空白或未知值转换成零。领域解释保留税目发布版次、百分比税率口径、同版异值隔离。只有所选范围内且有充分常规依据的记录列入当前收件；其他范围、待确认、历史和冲突分别保留结果，不用覆盖旧原文消除分歧。

## 关联资料与章注

`fixtures/source.json` 的 `resources` 是本地来源的 URL 路径到响应正文的映射；只绑定回环地址，不连接真实监管、银行或合作方。原文可通过目录声明的位置取得。同一来源也可发布关联资料与章注，当前示例的位置为 `/tax/CN/R2/relations/H-881` 与 `/tax/CN/R2/chapters/88`，字段保留来源的业务含义：

```json
{
  "crosswalk": [
    {
      "from": "H-88",
      "to": [
        "H-881",
        "H-882"
      ],
      "edition": "R2"
    }
  ]
}
```

```json
{
  "chapter": "88",
  "edition": "R2",
  "notes": "第88章章注：本版税目不包括特种设备。",
  "exclusions": [
    "H-882"
  ]
}
```

对应关系条目中的 `edition` 是目标税则所属的发布切面，可以与目录自身版次不同：来源允许对照表先更新、税则正文随后更新。章注中的 `exclusions` 是被章注排除的商品编码。

## 发布切面

适用范围采集从采购方使用的商品编码出发，按发布切面（版本）分别组合对应关系、章注与税则：只有同一切面内的资料才能拼成商品范围，跨切面拼接会得到来源从未发布过的适用范围。每个切面分别判定：

- `complete`：对应关系一致，目标编码的同版税则与相关章注齐备，商品例外已扣除；
- `gap`：仍有缺件（目录、税则、章注或关联资料未发布或未取得），原因逐条列出，不用相邻税目或旧税率补齐；
- `conflict`：同一切面内对应关系相互矛盾，或同版税目出现不同税率，不覆盖、不擅自合并。

对照表指向的后续版本目录按 `/tax/{国家}/{版本}` 推导取得；HTTP 404、403、503 不能自行解释为业务删除，只记为待采缺件。各国家（范围）独立采集、独立判定完成，已完整的国家先行交付，不等其他国家同步。

## 本地合作源

`fixtureSource` 支持独立实例、指定路径返回码、一次性来源故障、响应延迟与 `replace` 更新资源；访问记录保留实际请求路径，不凭空生成未收到的响应。测试在进程内操作夹具，不提供对外开放的管理接口。目录不承诺所有关联资料与当前目录同时发布。

## 原文和收件

原文字节按 SHA-256 寻址，SQLite 保存来源位置、观察时间、收件范围、业务身份、领域记录与决策。收到原文不等于领域接收成功；重复的同一内容不新增收据，同一身份的不同内容不会覆盖原件。`claims` 表保存每条采购编码在各自切面的领取范围（商品、被排除编码、缺件、原因与证据摘要），内容相同的再次确认只刷新确认时间不另起版本；更正对应关系后，受影响的领取范围产生新版本，旧版本保留备查，已确认且仍适用的资料不重新混成另一版。资料人员可用 `trace` 从一条接收结果查回税则、章注、编码对应的原文及其发布切面，并解释某个采购编码为什么需要继续采集。`.data/` 仅用于本机数据，演示使用临时目录，运行结束关闭服务并清理临时状态。
