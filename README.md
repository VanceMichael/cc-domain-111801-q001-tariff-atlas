# TariffAtlas

TariffAtlas 为业务资料员提供税目范围展开与原文保管，已支持来源目录预览、直接记录领取、税目发布版次、百分比税率口径、同版异值隔离以及按业务范围形成收件记录。原文与领域收件结论分开保存，便于复查来源内容。

协定升级前，采集任务可以从采购方使用的商品编码出发，收齐解释适用范围所需的税则、章注（商品例外）与跨版编码对应。对应关系允许先于税则正文更新，系统按发布切面（版本）分别组合资料：依据完整的商品范围先行交付，仍有空缺或相互冲突的分别说明原因，不用相邻税目或旧税率补齐；各国家独立判定完成，不等全部同步。资料人员可从一条接收结果查回各切面原文，并解释某个采购编码为什么需要继续采集；更正对应关系后，受影响的领取范围与完成判断随之变化，已确认且仍适用的资料不重新混版。

## 环境与运行

使用 Node.js 22.23.4，依赖版本由 `package-lock.json` 固定。仅使用 Node.js 内置模块，无需外部数据库进程或第三方运行服务。

```sh
npm ci
npm run build
npm test
npm run demo
```

`npm run demo` 在本机启动合作源，用独立临时目录完成真实领取、原文保存和领域接收，并演示一次从采购编码出发的适用范围采集：对照表先行更新到 R3 时 R2 切面先行交付、R3 切面说明待采原因，来源补齐 R3 后再次采集完成，输出实际结果后清理；不要求外网资料。`npm start` 可单独启动本地来源供交互查看，终端会打印实际回环地址，Ctrl-C 关闭。通过 `PORT` 指定监听端口，省略或设置为 `0` 时自动分配；仅监听回环地址。根路径返回可用资源目录与运行状态。

## 容器

```sh
docker build -t tariff-atlas:local .
docker run --rm --network none tariff-atlas:local
```

镜像构建时准备依赖，容器运行时不联网，演示只使用回环通信。可改用 `docker run --rm --network none tariff-atlas:local npm test` 运行回归。存储通过 `Archive` 传入本机目录，不包含生产账号、真实业务资料或凭据。

## 代码与来源约定

`src/source.mjs` 负责来源目录与原文身份，`src/interpret.mjs` 解释当前领域记录，`src/receiving.mjs` 决定选定范围内的收件结果，`src/coverage.mjs` 按发布切面组合对应关系、章注与税则并判定适用范围。`src/archive.mjs` 提供原文保管及收据、领取范围落库，`src/app.mjs` 连接日常业务（单表预览、直接领取、采购编码采集与接收结果追溯），`fixtures/` 与 `src/fixture-source.mjs` 提供可独立复查的本地合作源。详细字段与来源声明见 `docs/source-contract.md`。
